picoBuilder 사용법

    
    
      
  1. 보드 선택: 상단에서 Raspberry Pi Pico 또는 BBC micro:bit V2를 고릅니다. 생성되는 코드(machine / microbit 모듈)와 사용 가능한 노드가 보드에 맞게 바뀝니다.
    2. 
      
  2. 노드 추가: 왼쪽 팔레트에서 모듈/프로그램 노드를 캔버스로 드래그(또는 클릭)합니다.
    3. 
      
  3. 배선: 포트(동그라미)를 끌어 다른 포트에 놓습니다. Pico의 모든 핀(전원·GND 포함)과 모듈 핀을 자유롭게 연결할 수 있습니다.
        
    하드웨어 배선은 실선, 핀 참조·모듈 참조는 점선으로 표시됩니다.
    4. 
      
  4. 프로그램: 시작/무한 반복/타이머/버튼 눌림 이벤트 노드의 ▶ 실행 포트에서 동작 노드를 순서대로 연결합니다.
        값(●) 포트는 센서값·연산 노드와 연결하고, 연결하지 않으면 노드 안의 입력칸 값을 사용합니다.
    5. 
      
  5. 모듈 참조(◆): 모듈 헤더의 ◆ 포트를 프로그램 노드의 "모듈" 입력에 연결하거나, 노드의 드롭다운에서 모듈을 고릅니다.
    6. 
      
  6. 코드: 오른쪽에 MicroPython 코드가 자동 생성됩니다. 직접 수정하면 직접 편집 모드가 되며, "노드에서 생성"으로 되돌릴 수 있습니다.
    7. 
      
  7. 시뮬레이션(F5): 브라우저 안의 Python(Pyodide)으로 코드를 실행합니다. 버튼·가변저항·센서 값을 노드에서 조작해 보세요.
    8. 
      
  8. 보드 업로드: Chrome/Edge에서 "연결" → 보드 선택 → "업로드" 하면 main.py와 필요한 드라이버가 저장되고 실행됩니다. (MicroPython 펌웨어 필요 · micro:bit는 python.microbit.org 에서 설치)
    9.
